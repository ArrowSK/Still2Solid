# Milestone M3 — Production TripoSR adapter

## Goal

Replace the M1/M2 production-model placeholder with one real, auditable local inference path while preserving Mock3D as a safe fallback.

## Delivered

- TripoSR production adapter implementing the existing `ModelAdapter` contract.
- In-app install/reinstall/uninstall state for the TripoSR runtime.
- Pinned upstream source and model revisions.
- Git-blob verification for downloaded source files and SHA-256 verification for the model checkpoint.
- Verified local U2Net asset for optional foreground isolation.
- Isolated one-shot Python worker with no localhost server.
- CUDA, Metal/MPS and CPU runtime selection with explicit runtime validation.
- Apple-Silicon-friendly CPU marching-cubes shim so `torchmcubes` does not need to compile on macOS.
- Conservative Fast / Standard / Best production presets.
- Real worker stage progress, cancellation and error propagation.
- Real generated GLB preview in Three.js.
- Direct GLB export from the production preview.
- Mock3D fallback when production runtime conditions are not met.

## Quality presets

M3 intentionally uses lower extraction pressure than the upstream default because Still2Solid targets consumer hardware, including unified-memory Macs.

| Quality | Marching cubes | Renderer chunk | Texture |
| --- | ---: | ---: | ---: |
| Fast | 128³ | 512 | 512 px |
| Standard | 160³ | 768 | 1024 px |
| Best | 192³ | 1024 | 1536 px |

These are product presets, not claims about final quality equivalence. Real timing/ETA learning remains M4.

## 8 GB Apple Silicon behaviour

The M2 policy remains conservative: an 8 GB Apple Silicon system is `Memory constrained`, so TripoSR is not automatically recommended. M3 nevertheless allows an explicit **Install experimental** action. That action is a deliberate opt-in and selects TripoSR only after installation verifies successfully.

If memory/backend execution fails, the error is surfaced and Mock3D remains available. Still2Solid does not silently change the model or claim that the 8 GB path is guaranteed.

## Runtime prerequisite in M3 development builds

The installer currently requires Python 3.11 or 3.12 to be discoverable in order to create its private virtual environment. After creation, Still2Solid runs the environment's own Python and does not execute inference inside the caller's Python environment.

This is a development-milestone constraint, not the intended final end-user installation experience. Release packaging will bundle the required runtime later.

## Acceptance criteria

- [x] M1/M2 Mock3D workflow remains functional when TripoSR is absent.
- [x] TripoSR cannot become active before its installation manifest is complete and verified.
- [x] Source revision and checkpoint are immutable/pinned in code.
- [x] Failed checksum verification aborts and removes the staging installation.
- [x] No arbitrary model URL/model ID can be passed to the installer.
- [x] Production generation executes in a child process rather than the Tauri/UI process.
- [x] Production generation exposes stage progress and cancellation.
- [x] Runtime model downloads are blocked during inference.
- [x] Generated GLB can be previewed and exported.
- [x] CI validates TypeScript/Svelte, worker syntax and Rust compilation/tests without downloading model weights.
