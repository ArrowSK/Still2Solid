# M8 — Additional production model

M8 proves that Still2Solid's model architecture can support more than one production adapter without turning Model Manager into an unreviewed model browser.

## Delivered

Stable Fast 3D (SF3D) is the second production adapter.

- Source is pinned to immutable GitHub commit `ff21fc491b4dc5314bf6734c7c0dabd86b5f5bb2`.
- The gated Hugging Face repository is pinned to immutable revision `f0c9a8ffd62cb1bbc8a7a53c9f87a0be1b6be778`.
- `model.safetensors` is verified with SHA-256 `a3416e1cf654e7d4f5e75f116cec2c3f0a14501a77d30c2f6068bbda178de388` before activation.
- Selected upstream source blobs are checked against pinned Git blob hashes.
- Required DINO/CLIP support assets are prepared at install time so inference can run offline.
- Foreground isolation uses the existing local support path.
- Inference runs in a one-shot child process with cancellation and cleanup; no localhost model server is created.
- SF3D results enter the same canonical GLB, preview, export, timing and print-preparation layers as TripoSR results.
- Model Manager can install, uninstall and explicitly select SF3D.

## Licence and gate handling

SF3D is classified `conditional`, not `verified-permissive`.

Installation requires:

1. access to the gated upstream Hugging Face repository;
2. a user-provided Hugging Face read token;
3. explicit acknowledgement of the Stability AI Community License inside Model Manager.

Still2Solid does not accept the upstream gate on the user's behalf. The token is passed only to the installer process and is not written to application settings or the installation manifest.

Because the model is conditional/gated, SF3D is never an automatic recommendation even when the computer is powerful enough to run it.

## Hardware policy

The existing conservative M2 policy remains authoritative:

- Apple Silicon below 32 GB is memory-constrained for SF3D; upstream recommends CPU below that memory level.
- Apple-Silicon MPS support is treated as experimental, not as a blanket compatibility promise.
- Higher-memory Apple Silicon may be marked compatible but still requires explicit install/selection.
- CUDA-capable systems are assessed separately by detected accelerator information.

TripoSR remains the primary permissive production adapter for the intended lightweight workflow.

## Models not promoted to executable adapters

TRELLIS.2 remains catalogue-only because its current upstream requirement of Linux plus an NVIDIA GPU with at least 24 GB VRAM is outside the primary target. Models with incompatible regional licensing remain excluded rather than being exposed behind a warning.

## Acceptance boundary

M8 is complete in code when:

- at least two production adapters implement the shared local generation flow;
- the second adapter has an explicit licence/hardware/security review;
- all downloaded executable model assets use immutable revisions and integrity checks;
- conditional models require user action and are never silently auto-selected;
- credentials are not persisted;
- generation, progress, cancellation, canonical GLB handling and cleanup are connected end-to-end;
- automated checks validate UI/Rust/Python integration without downloading the multi-gigabyte model in CI.

Physical performance claims remain separate from architecture completion.
