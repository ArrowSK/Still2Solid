# Milestone M1 — Application shell + Mock3D

## Goal

Establish a runnable macOS Apple-Silicon desktop shell and a deterministic adapter that exercises the intended Still2Solid experience without downloading external model weights.

## Acceptance criteria

- [x] Tauri 2 desktop core exists.
- [x] Svelte/TypeScript UI exists.
- [x] Local image drag/drop and file selection.
- [x] Fast / Standard / Best quality presets.
- [x] Model explanation surface.
- [x] Advanced-mode shell with backend and foreground-isolation controls.
- [x] Deterministic Mock3D adapter implements the common model contract.
- [x] Generation reports stage, percentage, ETA and whether progress is estimated.
- [x] Generation can be cancelled.
- [x] Tauri core detects platform, architecture, CPU/chip, memory and preferred backend.
- [x] Three.js interactive textured preview.
- [x] Mock GLB export.
- [x] No external model weights, network inference or telemetry.

## Explicitly deferred

- M2: Model Manager and hardware-based model recommendation.
- M3: production TripoSR adapter.
- M4: persisted real-world timing/ETA profiles.
- M5: production asset/export pipeline.
- M6: print preparation.
- M7: signed/notarized release packaging.

## Local development

Prerequisites for contributors only: Node.js, npm and Rust.

```bash
npm install
npm run check
npm run tauri:dev
```

End users will not be expected to install these tools once release packaging is implemented.
